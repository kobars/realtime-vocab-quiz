## PR-123 — Keep a replaced socket's in-flight join from taking the session back

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Stop a replaced socket's `join`, already awaiting the store when a newer socket of the same user replaced it, from taking the presence back and closing the newer socket: a store fence on `join` (memory store and `join.lua`).
- **Prompt / interaction:** The agent got the confirmed finding with its reproduction, wrote a store contract test and a gateway test first, confirmed that each failed on the old code (the replaced connection's join was accepted on both stores; both sockets closed with 4001), then made the fix and updated the Redis and protocol specs. The review before the merge found the gateway check of the first version wrong; the agent removed it and added a test on a real memory store.
- **What was wrong or changed:** (1) The first draft of each gateway test failed `ruff` (two lines over the 100-character limit; one blank line too many), fixed before the commit. (2) The first version also added a gateway check that made a socket closed during its join (by a 1013 overload, say) skip `registry.bind` and `registry.replace` even when the join had committed: the closed connection kept the presence for good, because `Registry.drop` started no grace leave for an unbound socket, and the socket the join replaced stayed open though the store had fenced it. The check was redundant for the reported race, which the store fence already refuses, and its test used a stub service that never touched a store. The check and that test were removed; `api/tests/integration/ws/test_connections.py::test_a_socket_closed_during_its_committed_join_still_leaves_and_replaces` now catches it. The defect itself was an incomplete fix in PR-99, recorded in that entry.
- **Verification:** `make check` (exit 0); `make test-integration` (exit 0, 140 passed); the Redis case of the contract test failed with `join.lua` reverted and passed with the fence; `scripts/check_internal.py --commits origin/main..HEAD` (clean); tests `api/tests/contract/test_store_contract.py` and `api/tests/integration/ws/test_connections.py`.
