## PR-143 — Test the quiz lifecycle end to end over the gateway

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Check the quiz lifecycle as a client sees it, in one test file over the in-process WebSocket gateway: a player's finish with a provisional rank, the end at the deadline and through the host endpoint, `quiz_ended` with the top 50 and each socket's own final rank, `QUIZ_ENDED` for writes after the end while pages still answer, a late joiner, and a join after the end. No production code changes.
- **Prompt / interaction:** The agent first traced each lifecycle rule through the store scripts, the service and the fan-out and found it already implemented and tested piece by piece, then wrote end-to-end tests against the domain and protocol specs, ran them repeatedly to catch timing assumptions, and mutated the code (no own rank in `quiz_ended`; no deadline check in the domain) to confirm the tests fail.
- **What was wrong or changed:** Three wrong assumptions in the first draft of the tests, all fixed before the PR: (1) it expected a leaderboard after Bob's answer while the manual quiz clock stood still, but the memory store's tick token expires on the quiz clock, so the tick stayed busy and no frame came; the test now moves the clock by one tick. (2) It expected the host end's `endSeq` to be 1, but the join had already made the standings dirty and the tick had published `seq` 1; the test now compares the second call and the `quiz_ended` frame with the first call's `endSeq`. (3) Ann and Bob joined at the same quiz time with 0 points, so their order fell to the random user IDs and the `finished` rank failed about one run in six; Bob now joins 1 ms later. The review found one more: the host-end test claimed in its name that the end reaches every socket but opened only one, so a host end that reached a single socket would still pass; it now connects two players and checks that each gets `quiz_ended` with the host's `endSeq` and its own final rank (`test_the_host_end_reaches_every_socket_and_a_second_call_changes_nothing`).
- **Verification:**

  - `api/tests/integration/ws/test_lifecycle.py`: 4 passed, and passed on 15 repeated runs; dropping the own rank from `quiz_ended` fails all 4, removing the domain's deadline check fails 3.
