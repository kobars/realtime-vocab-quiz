## PR-146 — Renew presence on every node and keep the cap slot of a given-up close

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Implement the presence renewal of `docs/spec/redis.md` §3 (the `renew_presence` script, its memory twin, and a per-node loop that renews every 3 s for each served quiz with `staleMs = grace + one renew period`), and keep a socket's per-IP and process cap slots after its close is given up, until its close frame goes out or uvicorn reports the disconnect.
- **Prompt / interaction:** The agent got both defects with the spec sections, found that both stores still raised `NotImplementedError` for `renew_presence`, wrote the store contract tests and the two-node Redis test first, then the script, the loop and the endpoint change; each new test failed before its change (the given-up close test saw the handler done and `caps.total == 0`).
- **What was wrong or changed:** (1) The first draft of the endpoint split left an unused `path` variable and no import of `WebSocketState`; ruff caught both before the first test run. (2) The first draft of the given-up close test queued `websocket.connect` after the two inbound frames, so `accept()` would have read a frame first; the connect event now comes first. (3) DESIGN.md §15 still said the presence renewal had no test because its script was not written; it now names the two tests. (4) The review before the merge found that the first endpoint change only waited for the disconnect after a given-up close: the deadline had cancelled `ws.close()` before uvicorn wrote the frame, so a peer that read again kept an open, silent socket and its cap slot. The sender now shields the close and keeps it pending (`Sender.closing`), and the endpoint waits for that close or the disconnect, whichever comes first; `test_a_given_up_close_still_goes_out_once_the_peer_reads_again` fails without the fix. (5) The given-up close test asserted after a fixed `sleep(1.3)`, 0.25 s past the earliest give-up; it now polls until the close was tried and the registry let go. (6) `docs/spec/redis.md` §3's test list named two presence tests that were never written; it now names the tests that exist. The full `make check` once failed in `load/tests/test_bots.py::test_a_quiz_end_before_the_deadline_ends_the_cpu_window`, a CPU-share test that also fails at times without this branch's tests on a loaded machine; the rerun passed.
