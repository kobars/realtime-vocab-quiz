## PR-155 — Add PR guards and a review token budget to CI

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Enforce the pull-request rules of `AGENTS.md` in CI (`scripts/check_pr.py`: frozen acceptance paths, the 400-line limit, the `AI-Assisted:` trailer and plain commit subjects, the AI-LOG entry) and measure each PR's review input in tiktoken `o200k_base` tokens (`scripts/review_budget.py`, thresholds in `[tool.review-budget]` of `api/pyproject.toml`); add both as `ci.yml` jobs under the `ci-required` gate, with one list of generated files in `.gitattributes`.
- **Prompt / interaction:** The agent worked from a written list of checks, thresholds and output formats, wrote the two scripts around one shared change-listing module, tested them on throwaway git repositories with a stubbed token counter, and checked the CI jobs on this PR and on a scratch PR.
- **What was wrong or changed:** (1) The shared `pr_repo` fixture first lived in `scripts/tests/conftest.py`; mypy then failed with "Duplicate module named tests.conftest", because `api/tests/conftest.py` maps to the same module name, so the fixture moved to `scripts/conftest.py`, which pytest still loads for `scripts/tests/`. (2) The first draft of `scripts/review_budget.py` kept an unused stub function and import, and ruff flagged a shebang on files without the executable bit and unused test parameters; all were fixed before the first commit. (3) The first test helper in `scripts/tests/test_check_pr.py` put a defaulted parameter before a required one (a syntax error), caught on the first test run.
- **Verification:** `make check` (exit 0, 568 pytest and 349 Vitest tests); `uv run --project api --locked pytest scripts/tests/test_check_pr.py -q` (16 passed); `uv run --project api --locked pytest scripts/tests/test_review_budget.py -q` (9 passed); `make review-budget` (23,739 tokens, ok); `actionlint` on `.github/workflows/ci.yml` (clean); on this PR the `guards` and `review-budget` jobs pass; on a throwaway PR that edited `api/tests/acceptance/test_join.py` and set the limit to 1,000 tokens, `guards` failed on the edit and on the missing AI-LOG entry and passed once the `acceptance-change` label started a new run, and `review-budget` printed "Review budget exceeded: split this PR into smaller PRs" and exited 1.
