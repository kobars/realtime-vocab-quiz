- **Task:** Measure coverage in every CI test job, gate on the combined total (95%) and on a PR's changed lines (diff-cover, 90%), keep `make check`'s unit-only floor of 84 as a local signal, and upload the JUnit reports and coverage data as run artifacts.

The `make -n` call in the new JUnit test used a bare `make`, which ruff's S607 rule rejected in `make check`; it now carries the same `noqa: S607` as the repository's other `make` and `git` test calls. The diff-cover step first kept its exit code in a variable named `status`, which is read-only in zsh, so a local replay of the step failed; it is `rc` now (the workflow runs bash, where either name works).
