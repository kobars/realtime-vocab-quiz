## PR-161 — System tests and browser specs against the composed stack

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Test the composed stack (two API nodes, Redis and the edge nginx) end to end: a pytest system suite through nginx (`api/tests/system/`), Playwright browser specs with an axe scan (`web/e2e/`), the `make test-system` and `make test-browser` targets, and a CI workflow (`.github/workflows/stack.yml`) that builds the images, starts the `full` profile and runs both suites. An accepted upgrade now names its node in `X-Node-Id`, so a test knows which node holds each socket behind round-robin.
- **Prompt / interaction:** The agent read the compose file, the edge nginx config, the gateway and the web views, wrote the gateway header test first and saw it fail, then wrote both suites and ran them against a local stack. It checked that the system suite catches a broken edge by deleting the `Upgrade` header line from `infra/nginx/nginx.conf`: four tests then failed with 404 instead of 101.
- **What was wrong or changed:** (1) The first `test-system` recipe set `STACK_URL='…' $(PYTEST)`, but `$(PYTEST)` starts with `cd api &&`, so the variable reached `cd` only. It worked when `STACK_URL` was given on the make command line (make exports those), and failed with "set STACK_URL" without it; the recipe now sets the variable under `set -a`. (2) The first live-leaderboard spec matched a row's text against `/ 0$/`, but the row's cells render with no space between them (`#14Cy-…0`), so it timed out; the specs now assert on the score cell. (3) The browser target was first named `test-e2e`, which `make help` did not list, because its pattern matches only lower-case letters and dashes; it is now `test-browser`. (4) mypy rejected the first draft: a `UUID` passed as the string `submissionId`, and a list of httpx headers given websockets headers. (5) Running the system suite twice within a minute got 429 from `POST /api/tickets`: the cap test spends about half of each node's per-address ticket budget. The test's docstring and the PR description now say so.
