## PR-165 — Restyle the web client with our own playful design system and a dark theme

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Replace the neutral token set of the Vue client with a playful design system ("Clay": brand violet, role fills under dark text, a self-hosted rounded font, a 3 px outline, hard tinted shadows, spring touch feedback, an OS-driven dark theme), rewrite the UI spec's style sections and add ADR-010, then restyle the shadcn-vue primitives, the app shell and join screen, the question and feedback screens, and the leaderboard, podium and results on it, with a contrast test that recomputes every pair from `tokens.css`.
- **Prompt / interaction:** Claude Code worked from a written brief with the palette, type scale, shape, motion rules and acceptance criteria, computed every contrast ratio before writing the tokens, built the change in small commits with tests per part, and checked the built app in headless Chrome at 320 px and 1280 px in both themes.
- **What was wrong or changed:**
  - The first version of the clay utilities would have been dropped silently: tailwind-merge reads unknown `border-*`, `text-*` and `bg-*` classes as colors, so `cn('border-clay', 'border-input')` kept only `border-input` and `cn('text-title', 'text-night')` kept only `text-night`. `web/src/lib/utils.ts` now registers the utilities in their real class groups; `web/src/components/ui/ui.test.ts` (the `cn(...)` cases) catches a regression.
  - Moving the "+points" text into its own span removed the space before the speed-bonus text, because Vue drops whitespace-only text between elements on separate lines ("+133 pointsincluding a speed bonus"). The existing assertion in `web/src/views/PlayView.test.ts` caught it; the style now sits on the paragraph and the text node keeps its space.
  - The first toaster change put the caller's props after the clay options, so its unset boolean props would have reset `rich-colors`; the props now come first in `web/src/components/ui/sonner/Sonner.vue`.
  - Nunito has no `tnum` feature; its default figures measured 600 units wide at weights 500 and 800, so no numeric fallback font was added.
- **Verification:** `make check` green (vitest: 19 files, 583 tests; web build passes); the contrast pairs in `web/src/styles/contrast.test.ts`, the spec-table check in `web/src/styles/tokens.test.ts`, the primitive rules in `web/src/components/ui/ui.test.ts`; `vite preview` in headless Chrome showed no horizontal scroll, the font loaded, and requests only to the page's origin.
