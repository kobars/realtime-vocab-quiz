## PR-166 — Fix fan-out delivery: late joins, cross-node replacement, per-player cost and relay races

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Fix four problems in the fan-out path. (1) A replaced socket's late join reply could remove the newer socket from the registry's player map. (2) Nothing consumed the `control` channel, so a join on another node never closed the old socket. (3) The `quiz_ended` frame was validated and encoded once per player, and all local players went into one rank read. (4) Two relay races could drop the final frame or send a stale `rank_update`.
- **Prompt / interaction:** The agent got a written description of each problem with the failure scenario and a suggested fix. It wrote each failing test first, checked that it failed on `main`, then changed `api/src/quiz/adapters/ws/registry.py`, `api/src/quiz/adapters/redis/store.py`, `read_standings.lua`, `api/src/quiz/fanout/broadcast.py` and `api/src/quiz/fanout/tick.py`.
- **What was wrong or changed:** The suggested end-frame fix assumed that the published `quiz_ended` bytes end in `"you":null}` and could be cut there. That holds for the memory store only: the Redis script encodes the head with `cjson` (unordered keys) and appends `entries` last. The relay therefore encodes the shared frame once itself, and `api/tests/unit/fanout/test_relay.py::test_each_player_gets_the_end_frame_with_its_own_rank` publishes a frame in the Redis layout and checks every player's bytes against a full encode. The first splice called the codec's `encode` on `m.You`, which accepts whole messages only; mypy caught it, and the code now uses `model_dump_json`. In the new two-node test, the first version asserted that the new socket was still open after the cluster context had closed every client, so it failed; the assertion now runs inside the context. A new test name had a typo that the `typos` hook in `make check` rejected; it was renamed.

Failing on `main` before the change: `api/tests/integration/ws/test_connections.py::test_a_replaced_socket_whose_join_reply_comes_last_is_closed_with_4001` (`[] == ['u0']`), `api/tests/integration/test_two_nodes.py::test_join_on_other_node_closes_old_socket_4001` (timeout), three tests in `api/tests/unit/fanout/test_relay.py` (999 validations for 1,000 players; one read of 2,500 ids; a stale `rank_update` at seq 5) and `api/tests/unit/fanout/test_tick_faults.py::test_an_end_published_during_the_seq_read_still_reaches_every_local_player` (no `send_to`).
