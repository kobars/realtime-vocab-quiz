## PR-169 — Add screenshot baselines and a WCAG 2.2 AA browser suite for every screen

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Guard how the restyled client looks: a Playwright suite on the production build with a mocked backend that compares screenshots of eleven screens at 320, 768 and 1280 px in light and dark, and checks axe (WCAG 2.2 A/AA), sideways scroll (also at 200% zoom), 44 px targets and focus rings. It runs in a Playwright image pinned by digest (`make ui-check`, `make ui-baselines`, the CI job `ui`).
- **Prompt / interaction:** The agent got the screens, the matrix, the checks and the tooling limits. It read the client's protocol flow (`join` → `joined` → `resync` → `snapshot`) to write a scripted socket mock, ran the suite in the pinned image, generated the baselines there, and then changed a colour token on purpose to show the suite fails.
- **What was wrong or changed:** (1) The first screenshot limit, `maxDiffPixelRatio: 0.01`, did not catch a broken `--muted-foreground` token: the changed text covers only 0.05–0.4% of a page, so all 33 light screenshots still passed. The limit is now `maxDiffPixels: 50`, and with the same token change every light screenshot fails. (2) axe hung until the test timeout because the paused page clock also stops the timers it waits on; the accessibility test resumes the clock before the scan. (3) The join-error screen clicked Join, but the quiz ID error that the field's blur shows moves the button down, so the click landed elsewhere and the name error never appeared; the screen now submits with Enter. (4) The last-5 s screen ran the clock exactly 15 s, and the last animation frame fell just before that, so the ring still read 6 s; it runs 15.5 s. (5) The focus-ring test started tabbing from the control the screen had focused, so on some screens the first Tab left the page and nothing was checked; it now starts from the top of the page. (6) The first container command let pnpm put its store in the repository root; the store now goes to `/tmp` in the container.
- **Verification:** `make ui-check` (198 passed, twice); the token change above (`make ui-check UI_ARGS='--project=320-light --project=768-light --project=1280-light'`: 60 of 99 failed, all 33 screenshots and 27 axe tests); `make check` (exit 0); `uv run --project api pytest scripts/tests/test_repo_config.py` (26 passed), including `test_ui_specs_run_in_the_playwright_image_of_the_locked_version_pinned_by_digest`.
