## PR-186 — Restart the stopped node with compose start in make smoke-full

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Make `make smoke-full` (`load/smoke_full.py`) restart the API node it stops without recreating it, so a node started by `make demo` keeps the raised `PER_IP_CONN_CAP` that `scripts/demo.sh` exports only to its own compose calls.
- **Prompt / interaction:** The agent was given the defect (the restart used `docker compose up --detach --wait`, which recreated the node from the calling shell's environment and dropped the cap back to the default of 50). - **What was wrong or changed:** Nothing in the AI output needed a correction. The original restart command chose `up`, which recreates a container whose computed configuration differs from the running one; `start` reuses the stopped container and its settings.
