## PR-189 — Bound Redis commands with a timeout, refresh the load results and add two missing tests

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Give the Redis command and subscription pools a socket and connect timeout from settings, so a Redis that stops answering turns into `UNAVAILABLE` / HTTP 503 instead of a request held until nginx's 60 s proxy timeout; rerun the four load scenarios with the current bot swarm and quote the new files, with `completion` and `slo_met`, in `load/README.md` and `DESIGN.md` §9; test the question card's modifier-key guard and the export of `feed_subscribe_failures_total`.
- **Prompt / interaction:** The agent read redis-py 8.1's connection and pub/sub code to choose where the timeouts apply (the blocking pub/sub read passes no timeout, so a quiet subscription is safe), checked that `CLIENT UNPAUSE` itself waits for a `CLIENT PAUSE ... ALL` to end, and sized the test's pause so it ends on its own; it then ran the four load scenarios on the full stack and rewrote the measured tables from the result files.
- **What was wrong or changed:** The first draft of the paused-Redis test expected 200 from `POST /sessions` and a 503 body of `{"error": "UNAVAILABLE"}` alone; the route answers 201 and its error body also carries `message`, so the test now checks the status codes and the `error` field. The first 2,500-player load attempt lost the stack's containers part way through (94,910 failed opens, 98.82 % below 500 ms); that file was discarded and the scenario ran again on a fresh stack, so every committed run is a complete one. The command timeout gets a lower bound above the host end's 2 s `WAITAOF` wait, because a smaller value would fail every host end.
- **Verification:** `make check` (exit 0; 775 pytest, 13 acceptance and 657 Vitest tests); `make test-integration` (exit 0; 217 passed, acceptance on Redis 11 passed and 2 skipped as expected); without the timeout wiring the paused-Redis test fails (the request waits out the pause and answers 201), and without the modifier guard the new key test fails.
