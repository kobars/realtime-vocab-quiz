## PR-195 — Add a host page: create a quiz from a question set, share it, end it

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Build the client side of self-service hosting against the fixed HTTP contract (`GET /api/banks`, `POST /api/quizzes`, `POST /api/quizzes/{id}/end` with `X-Host-Token`). The work covers a quiet "Host a quiz" link on the join screen; a `/host` page to pick a question set, share the quiz (ID, link, copy button, client-side QR code) and watch the player count; End quiz with a confirm step; and every error state with its own copy. The host token stays in `sessionStorage`. The page has unit, visual and accessibility tests, a full-stack browser spec, and a UI spec section.
- **Prompt / interaction:** The agent built the page against mocked HTTP while the API side was built in parallel. It read the existing join screen, the preview client and the clay primitives, and reused them. It picked `uqr` (no dependencies) for the QR code, rendered as one SVG path in the role colours. Each set is one large button, so hosting takes a single click.
- **What was wrong or changed:** The join screen's new bank-list request broke five existing `JoinView` tests that counted every `fetch` call. Their stub now answers the bank list apart from the quiz lookups, which are counted on their own. In the first polling test, earlier tests' host panels stayed mounted. They answered the test's `visibilitychange` event and polled through the new fetch stub, so the count was wrong; `enableAutoUnmount` now unmounts each test's app. Polling first started at mount even in a hidden tab; it now starts and stops with the page's visibility only. The first screenshots showed the quiz ID broken over two lines at 320 px, so phones now use the 24 px size. They also captured the confirm screen scrolled, with the pointer hovering "Keep it open"; the screen now moves the pointer away and scrolls to the top first.
- **Verification:** `make check` (exit 0, 748 web tests). The visual and accessibility suite in the pinned Playwright image passed 272, with 10 skipped as before. Tests: `web/src/views/HostView.test.ts`, `web/src/views/JoinView.test.ts`, `web/e2e/fixtures/screens.ts` (screens `host`, `host-created`, `host-confirm`, `host-ended`) and `web/e2e/host.spec.ts` (browser job, full stack).
