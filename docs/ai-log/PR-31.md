## PR-31 — Add the black-box acceptance suite for joining, scoring and the leaderboard

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Write the acceptance tests for AC-1 to AC-6 before the server exists: a `quiz_server` fixture that builds the app with `quiz.main:create_app`, serves it on a free local port with an injected clock on the memory store (or the real clock on Redis), and drives it only over HTTP and the WebSocket protocol; the tests skip until the factory exists, and the folder is locked once merged.
- **Prompt / interaction:** The agent derived each test from the domain and protocol specs, defined the small HTTP and factory interface the harness needs in the `conftest.py` docstring, and checked the tests against a throwaway in-memory fake server kept outside the repository, including deliberately broken variants of that fake, before opening the PR.
- **What was wrong or changed:** (1) The first draft of the concurrent-duplicates test built its submission IDs as `[repeated, new] * 4`, so the "new" ID was the same four times and the test sent two repeated IDs instead of one repeated and four distinct ones; it now makes a fresh ID per position. (2) Running the suite against broken variants of the fake showed that the standings-order test passed a server that moves a player's reach time on a 0-point answer, and caught a missing `userId` tie-break only by chance with two tied players; the test now has three tied players and one of them answers wrong late. (3) The first version was 473 changed lines, over the 400-line limit; test names, the harness and its docstring were shortened without changing what the tests check.
- **Verification:** `make check` (exit 0; the 13 acceptance tests are collected, linted and type-checked, and deselected by marker); `cd api && uv run pytest tests/acceptance -rs` (13 skipped: "quiz.main:create_app does not exist yet"); against the fake server, 13 passed on the manual clock and 11 passed with 2 skipped in Redis mode; each of 12 injected bugs in the fake failed at least one test. Test files: `api/tests/acceptance/test_join.py`, `api/tests/acceptance/test_scoring.py`, `api/tests/acceptance/test_leaderboard.py`.
