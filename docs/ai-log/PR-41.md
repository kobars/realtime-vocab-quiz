## PR-41 — Follow the spec's pong rule in the seq tracker

- **Task:** Make `SeqTracker` (`web/src/protocol/seq.ts`) follow the protocol spec §3 rows for `pong`: ignore a `pong.seq` at or below `lastSeq` or `null`, and resync on a higher `pong.seq` only if `lastSeq` is still below it 1 s later.
- **Prompt / interaction:** The agent fixed a verified post-merge review finding of the tracker against the spec's `pong` rows, wrote the tests first, and checked that they fail against the previous `seq.ts`.
