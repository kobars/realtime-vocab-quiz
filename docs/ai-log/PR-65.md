## PR-65 — Results screen with a provisional rank and the podium

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Build the finished and results screens of UI spec §3.6: a provisional rank with the live board until the quiz ends, then the podium, the viewer's final rank from `you`, the rest of the top 50 and the same paging, with focus on the results heading (§6.2).
- **Prompt / interaction:** The agent was given the acceptance criteria and the UI spec sections, reused the merged leaderboard components (`LeaderboardPanel`, `LeaderboardRows`, `AllPlayers`) and wrote the view, the podium and component tests that drive them through the quiz store.
- **What was wrong or changed:** An earlier AI draft of this change omitted the spec's "until the quiz ends in m:ss" countdown, and its `you: null` test set `store.myRank = null` by hand, so it never proved that the store leaves the rank empty for a viewer who is not a player. The final version adds `quizMsLeft()` to the store and a one-second countdown in the view, and the `you: null` test reaches the ended state from real server frames only. The post-merge review found four more AI mistakes in the merged code, fixed in a follow-up PR: the list under the podium kept every rank above 3, so an ended `snapshot` of 60 players listed ranks 4–53; the podium put its items in DOM order 2, 1, 3, so a screen reader read second place first; the finished screen had no live region for the score or the rank (UI spec §6.3); and the store kept the live "Show all players" page across the end, so the results list showed "As of update N" rows from before it. Each now has a test in `web/src/views/ResultsView.test.ts` (the ended-snapshot top-50 test, the podium DOM-order checks, the live-region and 5 s throttle test, and the no-live-page-after-the-end test).
- **Verification:** `make check` green (15 web test files, 209 tests); `web/src/views/ResultsView.test.ts` covers the provisional rank and countdown, the switch to final results with focus, the podium order and paging, and fewer than 3 players with `you: null`.
