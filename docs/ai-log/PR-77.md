## PR-77 — Play view with the question screen and countdown ring

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Replace the quiz placeholder with `PlayView` (header, intro, question and results by phase) and build the question card and countdown ring of UI spec §3.3 and §5.3: keys 1–4, one answer per question, a pending state, a ring on the monotonic clock, and choices locked while the socket is down.
- **Prompt / interaction:** The agent was given the acceptance criteria and the UI spec sections, built on the merged quiz store (`msLeft()`, `pending`, `connection`) and wrote component tests that drive the view through the store with server frames and a fake clock.
- **What was wrong or changed:** The first AI draft of the 1–4 key handler called `event.target.closest(...)` on whatever target the event had; a key event dispatched on `window` has no `closest`, so the handler threw before choosing. The handler now checks `event.target instanceof Element` first, and the tests dispatch keys from the focused element. The first draft also covered feedback and status messages in one change of about 700 lines; this PR keeps the question screen, and the rest follows separately.
