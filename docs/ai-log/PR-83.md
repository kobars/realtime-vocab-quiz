- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Show the answer feedback after `answer_result` (UI spec §3.4, §5.2, §5.4, §6.2, §6.3): the chosen and the correct choice marked with an icon and a word, `+points` with the speed bonus or "Too late: 0 points", the points and the header score counting up over 600 ms (at once under reduced motion), "Next question" or "See my result" with the focus, and a polite live region announcing the result and the new score.

Found after the merge: (3) the header score counted up on every score change, so the jump after a rejoin animated too, and the reconnect test was made to wait instead of the behavior being fixed (UI spec §4.3 swaps a `snapshot` at once); now only a new `answer_result` counts it up, caught by the reconnect test (back to 50 ms) and "a rejoin swaps the header score at once" in `web/src/views/PlayView.test.ts`.
