## PR-9 — Add the Redis store spec and ADR-005 to ADR-008

- **Tool:** Claude Code (claude-opus-5-5)
- **Task:** Write `docs/spec/redis.md` (key schema, the seven Lua script contracts, one clock, the composite sorted-set score and its limits, coalescing across nodes without an owner, and its failure cases) and ADR-005 to ADR-008 in `docs/DECISIONS.md`.
- **Prompt / interaction:** The agent worked from a written list of the store rules (hash-tagged keys, the `seq` rule, one TTL, the composite score, the dirty gate with a 200 ms token) and the merged domain and protocol specs, and designed the script contracts, the tick loop, the failure table and the four ADRs itself.
- **What was wrong or changed:** While drafting, the agent first planned to run the end of the quiz inside the write script that hit the deadline; that would have made the scoring and join scripts increment `seq` and publish, which breaks the rule that only a publishing script increments `seq`. It caught this against the `seq` rule before writing the table: the refused script returns `QUIZ_ENDED` with `endSeq = nil` and the node calls the idempotent `end_quiz`. It also first planned presence as a plain set that `leave` removes from, so a late grace timer on one node could mark offline a player who had already reconnected on the other node; presence now maps each user to a connection ID and `leave` compares it first. The post-merge review then found ten gaps the agent had left in the script contracts, all fixed in a follow-up PR with the test that will catch each one named in §6 of `docs/spec/redis.md`: a `replacedConnId` that no node could act on across nodes, and that equalled the caller's own ID on a repeat join (`api/tests/integration/test_session.py`); presence that a crashed node never cleared (`api/tests/integration/test_presence.py`); no read of one player's rank at a frame's `seq` (`api/tests/integration/test_standings_read.py`); `serve_question` ignoring `finished` (`api/tests/integration/test_serve_script.py`); no check of `timeLimitMs ≥ 1` or a non-empty question list, so `T = 0` divides 0 by 0 (`api/tests/integration/test_create_quiz.py`); an unclamped join reach time (`api/tests/unit/test_memory_store.py`); a restart failure row that claimed a lost host end recovers from the deadline, and a restart `dirty` nudge outside any script (`api/tests/integration/test_deadline.py`, `api/tests/integration/test_tick.py`); and a clock step back that nothing could count (`api/tests/unit/test_answer_service.py`).
